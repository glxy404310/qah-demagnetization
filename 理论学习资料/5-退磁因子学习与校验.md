# 不同形状的退磁因子：从物理图像到矩形薄膜校验

本文对应项目《理论学习资料》第 5 项。统一使用 SI、三分量之和为 1 的约定；矩形尺寸均为**全长**。示例材料参数是教学假设，不代表某种真实 QAH 材料。

## 1. 先抓住物理图像

磁化可以用等效磁荷理解：体内是 `ρm = −∇·M`，表面是 `σm = M·n`。这里的磁荷是计算表示，并非实际磁单极子。

对均匀磁化，体磁荷为零，退磁场来自表面。沿厚度方向磁化的薄膜，上下两个大面带相反磁荷，内部产生较强的反向场；沿面内方向磁化，主要是侧面带磁荷，平均退磁代价通常较小。因此，薄膜的退磁能通常偏好面内磁化。

“退磁”描述的是自场的作用，不意味着磁化必然消失。最终磁化还受交换、晶体/界面各向异性、外场等影响。

## 2. 退磁因子到底定义了什么？

### 椭球：内部的每一点都成立

对给定均匀磁化的椭球，在其主轴坐标下：

\[
\mathbf H_d(\mathbf r)=-\mathbf N\mathbf M,
\qquad \mathbf N=\operatorname{diag}(N_x,N_y,N_z).
\]

这里内部退磁场也均匀。三个无量纲因子只由形状比例决定，且 `Nx+Ny+Nz=1`。一般椭球半轴为 `a,b,c`，例如：

\[
N_x=\frac{abc}{2}\int_0^\infty
\frac{ds}{(s+a^2)\sqrt{(s+a^2)(s+b^2)(s+c^2)}}.
\]

另两项置换半轴即可。相关推导可读 [Di Fratta 的作者原稿，第 3 节](https://arxiv.org/html/1505.04970v2)。经典来源为 [Osborn, Physical Review 67, 351–357 (1945)](https://doi.org/10.1103/PhysRev.67.351)。

### 矩形体：必须加上体积平均符号

长方体即使 `M(r)=Ms m0` 严格均匀，内部 `Hd(r)` 仍通常不均匀。本文用的是 magnetometric（磁矩平均，即磁性体积平均）张量：

\[
\langle\mathbf H_d\rangle_V=-\mathbf N^{(m)}\mathbf M,
\qquad
\langle\mathbf H_d\rangle_V=\frac1V\int_V\mathbf H_d(\mathbf r)dV.
\]

沿长方体边选择坐标轴时，体积平均张量的非对角项为零；局部场仍可有横向分量。下文省略上标 `(m)`，但始终指这个体积平均量。

这正是 [Aharoni, *Demagnetizing factors for rectangular ferromagnetic prisms*, J. Appl. Phys. 83, 3432–3434 (1998)](https://doi.org/10.1063/1.367113) 所讨论的类型。[作者机构记录](https://weizmann.esploro.exlibrisgroup.com/esploro/outputs/journalArticle/Demagnetizing-factors-for-rectangular-ferromagnetic-prisms/993263030503596)可核对摘要与书目信息。

**均匀磁化不等于均匀退磁场；近似单畴也不等于磁化处处严格相同。** 矩形边缘的磁化弯曲会使两种状态产生差别。

### 三种经常被混淆的量

| 名称 | 平均范围或定义 | 能否直接校验均匀矩形体的总退磁能？ |
|---|---|---|
| Magnetometric 因子 | 整个磁性体积的平均场 | 能 |
| Fluxmetric / ballistic 因子 | 相应中截面的平均场 | 通常不能 |
| 中心点因子 | 样品中心一个位置的局部场 | 不能 |

还可能遇到由磁化曲线、磁化率或非均匀平衡态反推的“有效退磁因子”；它不一定只是几何常数。

本文给定均匀 M 的几何体积平均张量满足 `tr N = 1`，不限于椭球。可从退磁势所用牛顿势的泊松方程理解这个迹恒等式。不要把其他“有效 N”的性质混到本定义中。

单位也要看定义：这里 H 和 M 都用 A/m，`Hdi=−Ni Mi`。CGS 文献可能写 `Hd=−4π N M`，其 N 仍然三项和为 1；也可能把 `4π` 吸收到 N 内，让三项和为 `4π`。不能只看到“CGS”就机械乘除。如果软件导出的是以 T 为单位的 `μ0 Hd`，应先除以 μ0，或者直接使用 `Ni=−〈μ0 Hdi〉/(μ0 Ms)`。退磁项的 `μ0 Hd` 也不能与材料内部的完整 `B=μ0(H+M)` 混为一谈。

## 3. 不同形状如何比较？

| 形状与方向约定 | 退磁因子（SI） | 要注意的条件 |
|---|---|---|
| 球体 | `Nx=Ny=Nz=1/3` | 给定均匀 M 时，内部场均匀 |
| 立方体 | 三个体积平均值也是 `1/3` | 内部场不均匀；不能据此当成球 |
| 很长的旋转椭球，长轴 z | `Nz→0, Nx=Ny→1/2` | 有限长度时需要椭球解析式 |
| 很扁的旋转椭球，短轴 z | `Nz→1, Nx=Ny→0` | 是椭球，不是平顶圆柱薄片 |
| 无限长圆柱，轴向 z | `Nz=0, Nx=Ny=1/2` | 圆截面、无限长度的理想极限 |
| 无限大平面薄膜，法向 z | `Nz=1, Nx=Ny=0` | 面内无限延展；有限样品有边缘修正 |
| 有限圆柱/圆盘 | 轴对称时 `Nx=Ny` | 内部场通常不均匀，要先指定平均定义 |
| 长方体 `Lx≥Ly≥t`，厚度沿 z | 通常 `Nx≤Ny≤Nz` | 用矩形体的体积平均解析结果 |

有限圆形/椭圆形平顶薄膜，不能直接使用同轴比椭球的公式当作精确答案。轮廓相似不意味着三维表面形状相同。

固定形状比例整体放大时，几何 N 不变；总能量却随体积增大，交换与退磁的竞争也改变，所以是否形成磁畴仍可能改变。

## 4. 退磁能让 N 成为可直接检验的量

一般状态的退磁能为：

\[
E_d=-\frac{\mu_0}{2}\int_V \mathbf M(\mathbf r)\cdot\mathbf H_d(\mathbf r)dV.
\]

对给定的均匀 M、均匀 Ms 和长方体主轴坐标：

\[
E_d=\frac{\mu_0M_s^2V}{2}
(N_xm_x^2+N_ym_y^2+N_zm_z^2).
\]

所以应**分别设置三次状态** `m=(1,0,0),(0,1,0),(0,0,1)`，在每一次中比较：

\[
\boxed{N_i^{\rm field}=-\frac{\langle H_{d,i}\rangle_V}{M_s}},
\qquad
\boxed{N_i^{\rm energy}=\frac{2E_d}{\mu_0M_s^2V}}.
\]

若输出的是退磁能密度 `ed=Ed/V`，则第二式分母中去掉 V。必须使用**退磁项自身的能量和场**，不能用总能量或总有效场替代。

离散平均为 `Σ Hd,k ΔVk / Σ ΔVk`，仅统计磁性区域。完整、等体积、等 Ms 的长方体网格才可以直接用算术平均。非磁性空气单元、部分填充网格和空间变化 Ms 均需另行处理。

## 5. 一个可以立刻复核的薄膜算例

以下是随附脚本计算的解析体积平均结果，不是微磁模拟输出。x、y 为面内方向，z 为厚度方向：

| 全尺寸 Lx×Ly×t（nm） | Nx | Ny | Nz |
|---|---:|---:|---:|
| 200×200×4 | 0.029568913 | 0.029568913 | 0.940862174 |
| 400×100×4 | 0.013690285 | 0.057140628 | 0.929169087 |
| 200×200×20 | 0.097461183 | 0.097461183 | 0.805077634 |

前两行面积、厚度相同，只有面内长宽比改变。长条的面内长轴 x 代价较低；但这不能单凭 N 就推断实际撤场后的磁畴。

对 `200×200×4 nm³`、`Ms=3×10^5 A/m`，设置 `m=(0,0,1)` 时应有：

\[
\langle H_{d,z}\rangle\approx-2.82259\times10^5\ {\rm A/m},
\qquad E_d\approx8.51272\times10^{-18}\ {\rm J}.
\]

中心点局部值则对应 `Nz,center≈0.981996674`。如果把它当成体积平均值，会比正确的平均 Nz 高约 4.37%。使用无限薄膜的 `Nz=1` 作为该有限样品的精确基准，也会高约 6.29%。

中心点公式还可以帮助核查场输出：令 `R=√(Lx²+Ly²+t²)`，则

\[
N_{z,\mathrm{center}}=\frac2\pi\arctan\frac{L_xL_y}{tR}.
\]

这里是连续几何中心的局部值；一个有限大小的中心网格输出可能是单元体积平均值，两者也不必相等。

## 6. 如何安排模拟校验？

1. **先对齐模型。** 完整长方体、均匀 Ms、周围为真空/近似非磁介质、开边界。实际全尺寸取 `nx dx, ny dy, nz dz`；不要把单元中心之间的跨度当成全尺寸。周期性薄膜和邻近磁体的场不能与孤立长方体的 N 比较。
2. **先算静态给定磁化的场。** 设置一个严格均匀的方向，直接调用退磁项的场/能量计算，不调用 `relax`、`minimize` 或时间演化。仅设置均匀初态、随后让它弛豫，会失去这项校验的前提。
3. **分别测三个主轴。** 保存平均退磁场、退磁能、Ms、磁性体积、实际尺寸、网格、边界条件和软件版本。计算上面的两个 Ni，并与解析值比较。
4. **检查定义和恒等式。** 看符号、`Nx+Ny+Nz≈1`、方形样品 `Nx≈Ny`，以及场法和能量法是否一致。平均横向场应接近零；这并不要求每个单元的横向场为零。不要把三项强制归一化为 1 来掩盖错误。
5. **报告误差。** 对每项报告 `ΔNi=Ni,num−Ni,analytic` 和 `|ΔNi|`；Ni 很小时，相对误差会被放大。可先以绝对误差 `10^-4` 作为课程项目的排错起点，实际容限应由求解器精度和研究目标决定。
6. **再研究自由演化。** 静态校验通过后，加入交换、各向异性和外场，运行弛豫/磁滞模拟。这时比较磁畴、能量、剩磁、翻转行为，并另做网格收敛检查。

**一个重要数值细节：** 若均匀长方体被完全铺满，退磁核精确计算单元的体积平均场，则分格求和理论上与整体解析能量一致，粗网格也能通过这一项测试。它只能说明均匀态退磁计算正确，不能说明粗网格能够解析畴壁。若使用点采样场、近似核或有限元外部边界，则还需要检查相应的离散与边界收敛。NIST 的[均匀矩形体基准](https://www.ctcms.nist.gov/~rdm/std2/donahue/extra.html)直接展示了这一区别。

可补充 `m=(1,1,0)/√2` 的均匀态：解析能量应为 `μ0 Ms² V (Nx+Ny)/4`，帮助检查轴和交叉项。它仍是静态给定磁化测试。

### Fidimag 的最小调用方式

在已有 `sim` 与 `demag` 对象、且整个网格就是均匀材料长方体时，可以使用如下思路。此段已对照[官方 Demag 源码](https://raw.githubusercontent.com/computationalmodelling/fidimag/master/fidimag/micro/demag.py)核查接口，**本环境尚未安装并运行 Fidimag**：

```python
import numpy as np

# 新建验证模型时只需添加退磁项：
# demag = Demag(pbc_2d=False, calc_every=0)
# sim.add(demag)
for i, direction in enumerate(np.eye(3)):
    sim.set_m(tuple(direction))
    hd = demag.compute_field().reshape((-1, 3)).copy()  # H，A/m
    ed_total = float(demag.compute_energy())            # J
    n_field = -hd[:, i].mean() / Ms
    n_energy = 2 * ed_total / (mu0 * Ms**2 * V)
    print(i, n_field, n_energy)
```

这里 Ms、V、mu0 需由实际模型给出；V 用 m³。不要把此前弛豫后读出的 `sim.field` 当成单独的退磁场。

## 7. 均匀磁化假设如何限制结论？

对弛豫后的非均匀状态，一般不能使用：

\[
\langle H_{d,z}\rangle=-N_z\langle M_z\rangle,
\qquad
E_d=\frac{\mu_0V}{2}\langle\mathbf M\rangle^T
\mathbf N\langle\mathbf M\rangle.
\]

原因是退磁作用具有空间耦合，能量依赖完整的 M(r)，不仅是净磁矩。同样接近零的平均磁化，可能来自不同磁畴或涡旋，退磁能并不相同。`−〈Hd,z〉/〈Mz〉` 在 `〈Mz〉≈0` 时还可能发散；它不能被解释成新的几何 Nz。

即使磁化分布看起来近似单畴，也应检查它与严格均匀态的偏离。强外场可以让 M 更接近均匀，但不保证矩形体内处处严格均匀。因此，校验代码时最清楚的操作是直接规定 M 后计算场。

## 8. 和面外各向异性、QAH 项目的联系

对均匀宏自旋模型，单轴各向异性能密度取 `Ku(1−mz²)`，易轴为 z。比较沿 z 与沿 x 的状态：

\[
e_x-e_z=K_u-\frac{\mu_0M_s^2}{2}(N_z-N_x).
\]

因此在 xz 平面内可以定义

\[
K_{\mathrm{eff},xz}=K_u-\frac{\mu_0M_s^2}{2}(N_z-N_x).
\]

正值表示该均匀模型偏好 z。若要与所有面内方向比较，使用 `min(Nx,Ny)`；只有无限薄膜近似才简化为 `Keff≈Ku−μ0 Ms²/2`。

这个判据比较的是**均匀态**，不足以排除多畴、边缘失稳、其他亚稳态或热激活翻转，也不能直接给出真实矫顽场。若模拟已显式加入完整退磁项，通常应输入本征 Ku；不能再把含同一退磁贡献的有效各向异性重复计入。材料文献中的 Ku 或 Keff 需要先核对定义。

对本项目而言，N 提供形状各向异性的基线；后续微磁学负责验证能否保持期望的面外磁化分布。两者都不直接等于 QAH 霍尔电导的计算。

## 9. 随附解析计算脚本与公式

辅助目录中的 [rectangular_demag.py](辅助文件/output/demag-learning/rectangular_demag.py) 仅用 Python 标准库。它实现 Newell 的长方体自作用解析式，与均匀 M 的 Aharoni 磁矩平均因子对应同一个几何量；**不是声称逐行复刻了 Aharoni 原文公式**。

```powershell
python 辅助文件/output/demag-learning/rectangular_demag.py 200 200 4 --ms 300000 --check
```

命令行的三个尺寸单位是 nm。Python 函数 `rectangular_factors(lx,ly,lz)` 则允许任意共同长度单位，因为它仅计算形状比例。输出中同时标明体积平均 N、中心点 N、三次主轴均匀状态各自的场和能量。三个输出分量对应三次不同的磁化状态，不是同一次状态的局部场向量。

为便于审查，计算核心的紧凑写法为：对非负 x,y,z，令 `r=√(x²+y²+z²)`，

\[
\begin{aligned}
f(x,y,z)={}&\frac{(2x^2-y^2-z^2)r}{6}
-xyz\arctan\frac{yz}{xr}\\
&+\frac{y(z^2-x^2)}2\operatorname{asinh}\frac{y}{\sqrt{x^2+z^2}}
+\frac{z(y^2-x^2)}2\operatorname{asinh}\frac{z}{\sqrt{x^2+y^2}}.
\end{aligned}
\]

零坐标处按连续极限取值。以全尺寸 a,b,c：

\[
N_x=\frac{2}{\pi abc}
\sum_{i,j,k\in\{0,1\}}(-1)^{i+j+k}f(ia,jb,kc),
\qquad N_y=N_x(b,a,c),\quad N_z=N_x(c,a,b).
\]

这里最后两个 `Nx(…)` 指同一计算函数的尺寸置换。公式和参考数据可对照 [OOMMF 作者的 demagcoef.cc（源码镜像）](https://raw.githubusercontent.com/fangohr/oommf/master/oommf/app/oxs/ext/demagcoef.cc)；原始文献为 [Newell, Williams & Dunlop, JGR 98, 9551–9555 (1993)](https://doi.org/10.1029/93JB00694)。OOMMF 的[官方退磁项说明](https://math.nist.gov/oommf/doc/userguide21a1/userguide-xml/sec_oxsEnergies.html)也说明了均匀单元磁化与体积平均场约定。

这个教学实现使用双精度，薄膜比例极大时会有相消误差，因此限制最大边/最小边不超过 1000；该界限是保守的使用范围，不是严格的误差保证。更极端的薄膜应使用高精度或稳定改写的自作用公式。脚本不通过强制归一化修正结果。

已运行的 `--check` 包括 OOMMF 公布的独立 Maple 基准值、轴置换、尺度不变性、正值与迹检查。独立参考值的最大绝对误差约 `7.5×10^-15`；所选测试几何的最大迹误差约 `4.1×10^-12`。这验证了解析脚本，**没有替代真实微磁求解器的运行验证**。具体输出保存在 `example_200x200x4.json`。

另用矩形表面磁荷的立体角场做了独立体积数值积分，不调用 Newell 函数。对 `200×200×4 nm³`，每轴 24、48、96 个 Gauss–Legendre 节点时，Nz 绝对误差分别约为 `4.46×10^-5`、`2.89×10^-6`、`1.84×10^-7`，随积分加密趋近解析体积平均值。结果记录在 `independent_quadrature_check.json`；这也是静磁学积分检查，不是 Fidimag 运行结果。
