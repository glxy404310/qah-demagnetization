# MuMax3 诊断记录

本目录不是通过验收的薄膜结果。正式结果为上一级的 `oommf_*` 目录。

2026-11-08 下载官方 MuMax3 3.12 Windows CUDA 12.9 包（commit `6e5c98bb`），
RTX 5060 Laptop 的 CUDA 初始化成功，实际使用 cc=120 PTX。
但 `-paranoid` 卷积自检失败：最大差值 `0.38552275`，阈值 `1e-6`。
同步 CUDA 模式及直接本机运行也复现失败，4×4×4 小立方体自检同样失败。
日志见 `mumax3_selftest.log`，输入见 `mumax3_square.mx3`。

为诊断而单独关闭自检、只计算静态均匀磁化时，`DemagAccuracy=8` 与 `32`
给出的平均 `B_demag,z` 分别为 `-0.35447642 T`、`-0.35465118 T`，
仍未达到本项目规定的 `|ΔN|<1e-4`。这些值不得用于物理结论。

本次不修改求解器源码，也不把跳过自检当作通过验收。改用 OOMMF 完成基准。
自检失败的根因尚未确认，不能据此认定显卡硬件故障或所有 MuMax3 版本都不适用。
进一步排查可比较自检程序的 Ms 数组、单位约定及不同官方构建。

`results_2nm` 是最初脚本变量名错误的空输出；其余三个小目录是失败自检的原始输出。
