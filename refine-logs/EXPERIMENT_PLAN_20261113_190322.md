## 3. 固定模型与几何

| 项目 | 主实验设置 |
|---|---|
| 求解器 | 沿用 OOMMF 2.0b0；Python 处理数据；先以单任务、8 CPU 线程试运行，再按当前硬件校准 |
| 材料 | Ms=3×10⁵ A/m，A=5×10⁻¹² J/m，Ku=8×10⁴ J/m³，易轴 z；均为教学参数 |
| 弛豫 | α=0.5，γG=2.21×10⁵ m/(A·s)，沿用 RKF54、关闭进动；仅研究静态/准静态状态 |
| 环境 | 零温、开放边界、无缺陷、无 DMI；交换、单轴各向异性、完整退磁及外场能 |
| 面积、厚度 | S=40,000 nm²，t=4 nm；目标磁性体积 160,000 nm³ |
| 网格 | 主网格 2×2×2 nm；复核 1×1×1 nm |
| 停止条件 | 每个弛豫场点最大 dm/dt≤0.01 °/ns；复核用 0.005 °/ns；达到迭代/时间上限记为未收敛 |
| 外场约定 | 配置与作图用 b=μ₀Hext（T），输入 OOMMF 前换算 Hext=b/μ₀（A/m）；b 不是样品内部总磁感应强度 |

| 形状标识 | 名义平面尺寸 | 选择理由 |
|---|---|---|
| square | 200×200 nm | 与已有基准完全衔接 |
| circle | 半径 √(40,000/π)≈112.838 nm | 同面积、无矩形尖角 |
| rectangle | 400×100 nm，长轴 x | 长宽比 4，面积严格相同，1/2 nm 网格均可整除；这是本计划选定值 |

圆形按磁性掩膜建模，磁体外 Ms=0；所有均值与积分只在磁性单元内计算。每张网格输出磁性单元数、实际面积、实际体积、轮廓图及面积偏差。优先保留同一名义半径并要求面积偏差≤0.5%；若失败，细化几何或用保持中心对称的小幅边界校正，并记录等效半径。不能通过改变 Ms 来补偿体积。圆形若与其他形状的差异接近面积/边界误差，须进一步检查边界采样或细化网格后才给出排序。

由已有基准参数估算：交换长度约 9.40 nm；方形均匀态有效各向异性约 2.85×10⁴ J/m³；用 π√(A/Keff) 得到畴壁宽度尺度约 41.6 nm。这些只用于选择网格和理解能量，不用于证明单畴基态。完整计算退磁能后不再额外添加形状各向异性能。

## 4. 必做实验块

### B0：环境恢复与基准复核

目的：确认原结果可读取、求解器可在当前机器可靠运行。

1. 恢复项目独立 Python 环境与依赖；从官方来源恢复指定 OOMMF/Tcl，记录版本、校验和、路径及当前硬件。保留原环境记录，新环境另存。
2. 将已有原始数据复制到新的复核目录后运行分析，避免覆盖原摘要与图片；要求原 50 项检查仍通过。
3. 在新目录重跑方形 2 nm 的固定 z 磁化和近 +z 零场弛豫，核对退磁因子、能量与收敛指标，记录当前耗时和内存。
4. 扩展模型生成、几何掩膜、初态、外场路径、状态继承及输出记录。现有脚本只支持方形单阶段，不能直接用于圆形或磁滞；原分析脚本的固定体积、全盒平均也须在新分析模块中改为磁性体积平均。

通过条件：固定态无磁化更新，Nz 与解析值绝对误差<10⁻⁴；零场弛豫收敛并复现近 +z 状态；从场点保存并重载状态的测试通过。失败时先修单位、掩膜、输入或环境，暂停批量计算。

输出：新环境清单、基准复核报告、可追溯的通用输入与运行器。

### B1：三种形状的静态退磁场

任务：3 种形状×x/y/z 三轴=9 个固定均匀态，方形已有 3 组可在 B0 通过后复用，新增圆形和长方形 6 组。禁止先弛豫再计算几何退磁因子。

指标与校验：

- 场法 Ni=−〈Hd,i〉/Ms，能量法 Ni=2Ed/(μ₀Ms²V)，用实际磁性体积。
- 三个方向均无磁化更新；两种方法的 Ni 绝对差<10⁻⁸，ΣNi 与 1 的差<10⁻⁶。
- 方形、长方形与已有长方体解析方法对照，绝对误差<10⁻⁴；圆盘不套用长方体或椭球解析值。
- 检查中心对称几何的对称性；输出 Hd,z 云图、统一物理坐标剖面、体积平均及分位数。边缘极值另列并标注网格，不能单靠极值排序。

成功标准是计算可验证、误差可解释；不要求形状差异必然很大。目标图表：退磁因子对比表、三形状场图与剖面对比。

### B2：多初态零场弛豫与饱和撤场

每形状采用 8 个零场初态，共 24 组（方形已有近 +z 一组可复用）：

1. 近 +z：normalize(0.01,0,1)。
2. 近 −z：取上一初态的整体反向。
3. 近 +x：normalize(1,0,0.01)。
4. 近 +y：normalize(0,1,0.01)。
5. 上下双畴：沿 x 分界，使用连续过渡畴壁并逐单元归一化，记录壁宽和方向。
6–8. 以 +z 为主、叠加小幅空间随机横向扰动（幅度 0.05）的三个初态，种子 11、22、33；保存生成定义与实际场文件。跨网格复核使用相同物理扰动场采样，不重新生成无关噪声。

比较〈mx,my,mz〉、〈|mz|〉、mz<0 体积分数、各能量密度、磁化图及收敛指标；能量最低者称“所测试初态中的最低能态”。不同初态落入不同状态时分别报告，不把它们平均成一个虚构磁畴。

**饱和撤场：** 从略倾斜初态在 b=+0.6 T 预备弛豫，验证 〈mz〉≥0.999、反向体积分数为零且收敛；若未饱和，以 0.2 T 增量扩展试探场，并让三形状使用共同的已验证扫描端点。连续逐场降至零，继承上一场点状态；主路径可与 B3 的下降支完全复用。在零场提取 Mr+/Ms；负饱和后返回零场同样提取 Mr−/Ms。直接零场初态的结果不称为剩磁。

目标图表：多初态能量与状态表、撤场零场磁化图、剩磁对比。此块与 B3 的零场记录共享，不重复计算相同路径。

### B3：完整准静态磁滞与翻转机制

主路径 b：+0.6 T→−0.6 T→+0.6 T，初始步长 0.02 T，明确包含零场；若端点通过上述规则扩大，重新生成共同路径。±0.6 T 时每个完整循环有 121 个场点，三形状共 363 个场点，包含初始饱和点且折返点不重复。

- 每点继承前一点磁化并独立检查收敛，不能逐点重新初始化；运行前保存路径清单。
- 在〈mz〉突变、过零或畴结构明显改变的区间，依次采用 0.01、0.005 T 场步，必要时至 0.0025 T。从转变前已收敛检查点沿正确扫描方向重放加密区间及后续路径；不能对粗曲线插值冒充复算。
- 记录两支过零场 Hc−、Hc+，报告 b 单位的矫顽场幅值 (bc+−bc−)/2。跳跃翻转优先报告夹逼区间及半宽，区间中点可作估计；平滑过零可插值并明确方法。
- 保存饱和点、两支零场、翻转前后磁化和能量；用局部成核、畴壁移动或近一致旋转解释曲线。

**对称性处理：** 轴向磁化与反向外场可能形成零力矩驻点，因此低 dm/dt 不足以保证状态稳定。在首次翻转附近及出现异常“不翻转”的场点，对保存态施加预先规定的小横向扰动后重新弛豫。以归一化前横向幅度 ε=10⁻³ 为起点，对关键场点比较 ε=10⁻⁴ 和 10⁻²，三形状使用同一规则；区分原始路径和扰动检验路径，不能挑选较好结果。若翻转场对扰动敏感，报告区间与协议依赖，必要时用统一扰动规则重跑三条曲线。这是零温稳定性检验，不是热噪声模型。

目标图表：三形状往返磁滞曲线、Mr/Hc 表、翻转前后磁畴与能量变化。若三形状均近单畴且曲线接近，保留这一结果。

### B4：数值可靠性与结果汇总

| 检查 | 必做范围 | 本计划拟定的验收目标 |
|---|---|---|
| 2→1 nm 网格 | 三形状固定三轴（方形可复用）；每形状至少两个代表零场态；三形状完整磁滞路径 | Ni 变化≤10⁻³；Mr/Ms 变化≤0.01；关键能量密度变化≤1%；翻转模式无未经解释的改变 |
| 翻转场步 | 三形状两条支路的翻转区 | 再减半场步后 bc 变化≤max(2 mT, 5%×|bc|)，且保留实际过零区间 |
| 停止阈值减半 | 每形状一个零场态及两支翻转区 | Mr、bc 满足上述目标；各点实际达到更严阈值 |
| 扰动/边界 | 异常驻点、翻转区；圆形面积或网格误差影响排序时 | 排序不由扰动幅度或边界取样决定；否则给出分辨率或协议限制 |
| 输出一致性 | 所有正式场点 | 磁性单元的磁化单位向量模长误差<10⁻⁶；能量项求和一致；场文件、输入与元数据对应；无未收敛点混入正式曲线 |

上述是预先指定的工程验收目标，不是保证所有算例都会满足的物理定律。若形状差异小于验收误差，应继续收紧误差或明确无法排序。固定场弛豫检查能量下降；不同外场之间总能量不要求单调。

最终比较表包含：几何实际面积、Nx/Ny/Nz、两支剩磁、两支过零区间与矫顽场幅值、反向体积分数、磁畴类型及数值不确定度。依据这些结果给出特定参数范围内的形状建议。

**耗时依据：** 历史记录中，2 nm 收紧阈值的近均匀态耗时约 9.43 秒，1 nm 零场态约 103.87 秒，均为旧机器上 8 线程结果，不能当作当前硬件或复杂磁畴的实测速度。

执行后先用当前机器的试运行记录每类任务中位耗时。预算公式为 Σ(该类场点数×实测单点时间)，另记录启动开销、峰值内存与输出大小。仅作排期示例：2 nm 若每点 10–60 秒，363 点约 1–6 小时；1 nm 若每点 100–300 秒，完整三曲线约 10–30 小时。加密、难收敛状态和环境恢复另计；不承诺这一估计必然实现。GPU 预算为 0，暂不租用计算资源。

存储先预留 5 GB 并按首条曲线校准：2 nm 方形每份双精度三分量场约 0.48 MB，1 nm 约 3.84 MB；圆形外包盒还含非磁性单元。保存每场点磁化检查点及标量表，完整退磁场/有效场优先保存关键点与验证点。先串行运行，避免已有启动命令中的 `-kill all` 干扰其他 OOMMF 作业；如需并发，先隔离服务与输出。
