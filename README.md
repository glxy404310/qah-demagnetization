# 基于微磁学模拟探讨量子反常霍尔效应的退磁场效应

本项目为电磁学课程项目，围绕铁磁薄膜的退磁场与磁畴结构，研究几何形状对面外磁化稳定性的影响，并讨论其对量子反常霍尔效应（QAH）器件设计的启示。

项目按照 **理论学习 → 模拟实验 → 数据分析 → 总结与优化** 的顺序开展。

## 1. 项目目标

- 理解退磁场、磁各向异性与交换作用之间的竞争关系。
- 建立不同几何形状的铁磁薄膜模型，比较退磁场分布和磁畴结构。
- 计算退磁因子，模拟磁滞回线，分析剩磁与磁化翻转行为。
- 根据模拟结果，提出有利于稳定面外磁化的形状设计建议。

## 2. 研究范围

本项目以具有面外易磁化轴的铁磁薄膜作为磁性模型，研究 QAH 相关的磁性问题。

微磁学模拟能够描述磁化分布、退磁场和磁畴演化，但不能直接计算量子化霍尔电导。因此，项目结论应表述为“为 QAH 器件提供更有利的磁性条件”，不能仅凭磁化稳定就认定实现了 QAH。

初期采用均匀材料参数、零温近似，不加入缺陷、热涨落和复杂界面作用。材料参数未确定前，可以先开展参数化模型研究；使用真实材料参数时，需要记录文献来源和适用条件。

## 4. 模拟实验方案

### 4.1 软件与参数

本机基准模拟已选用 **OOMMF 2.0b0（Windows CPU 版）**，使用 Python 进行数据处理与绘图。2026-11-08 已完成首个方形薄膜的退磁场校验、零场弛豫和网格复核，详见 [基准模拟记录](simulations/baseline/README.md)。MuMax3 3.12 能识别本机显卡，但本次卷积自检未通过，暂未作为已验证求解器。

需要记录的主要参数包括：

| 参数 | 符号 | 单位 |
|---|---|---|
| 饱和磁化强度 | Ms | A/m |
| 交换刚度 | A | J/m |
| 单轴各向异性常数 | Ku | J/m³ |
| 阻尼系数 | α | 无量纲 |
| 薄膜尺寸与网格尺寸 | — | nm 或 m，输入时统一单位 |

各向异性易轴设置为薄膜法向，即 z 方向。明确软件使用的外场单位，区分 H（A/m）与 μ₀H（T）。

### 4.2 几何模型与变量控制

先比较三种基础形状：正方形、圆形和长方形薄膜。若时间允许，再增加椭圆形或扫描长方形的长宽比。

- 基础比较保持材料参数、厚度和面积一致，尽量只改变形状。
- 长宽比扫描保持面积与厚度一致。
- 厚度或尺寸扫描单独开展，避免同时改变多个变量。

### 4.3 模拟步骤

1. **建立基准模型**：从简单薄膜开始，确认几何、单位、能量项和输出设置正确。
2. **计算退磁场**：将磁化分别固定为 x、y、z 方向的均匀状态，输出退磁场和退磁能，用于比较几何效应及计算平均退磁因子。
3. **观察零场磁畴**：从面外饱和态撤去外场并弛豫，观察剩磁和磁畴；补充不同初始磁化状态，检查是否存在不同亚稳态。
4. **模拟磁滞回线**：沿 z 方向从正饱和场逐步扫描到负饱和场，再返回；每一步继承上一场点的磁化状态并弛豫。
5. **检查结果可靠性**：缩小网格和关键翻转区间的磁场步长，确认主要结论不依赖数值设置。

网格需能够分辨交换长度和畴壁结构；曲线两端应达到饱和，各场点应满足所用求解器的收敛标准。

## 5. 数据分析

| 分析内容 | 主要输出 | 用途 |
|---|---|---|
| 退磁场分布 | 场分量云图、中心与边缘剖面 | 比较场的不均匀性及边缘效应 |
| 平均退磁因子 | Nx、Ny、Nz | 比较均匀磁化条件下的形状效应 |
| 磁滞回线 | 平均 Mz/Ms 与外场的关系 | 提取归一化剩磁和矫顽场 |
| 磁畴结构 | 零场及翻转前后的磁化图 | 判断单畴、多畴和翻转方式 |
| 能量变化 | 交换能、各向异性能、退磁能等 | 解释不同磁化状态的形成原因 |

对于沿 i 方向均匀磁化的模型，可由体积平均退磁场计算磁矩平均退磁因子：

```text
Ni = -〈Hd,i〉 / Ms
```

这里的平均仅在磁性体积内进行。矩形等非椭球样品的局部退磁场通常不均匀，平均退磁因子不能替代完整的场分布；形成磁畴后，也不应直接套用上述均匀磁化公式。

## 6. 方案优化与结论

综合比较面外剩磁、磁畴均匀性、磁化翻转行为和能量，判断哪些形状更有利于保持面外磁化。

优化建议应说明适用的材料参数、尺寸和厚度范围。零温弛豫得到的稳定状态只说明所测试条件下的静态或亚稳行为；若要讨论热稳定性，还需要进一步研究能垒或热涨落。

- 剩磁状态与磁畴结构对比，以及必要的网格收敛检查。
- 稳定面外磁化的形状设计建议。
- 课程项目报告与汇报材料；结果充分时，可进一步整理为教学或科研论文。
